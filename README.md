# Snake Game

A simple Snake game built with Python.

## About

This project is a small implementation of the classic Snake game, created as a simple Python project and GitHub showcase.

## Features

- Classic Snake gameplay
- Keyboard-controlled movement
- Food collection and score tracking
- Collision-based game over
- Simple and lightweight implementation

## Requirements

- Python 3.x
